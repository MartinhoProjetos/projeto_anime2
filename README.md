-Projeto Anime — One Piece (HTML Avançado)

Este projeto foi desenvolvido como atividade prática da disciplina de HTML Avançado, focando exclusivamente no uso de marcação semântica, acessibilidade e estruturação de dados sem qualquer utilização de estilização (CSS) ou scripts (JavaScript).

-Páginas do Projeto (11 Páginas)

 biografia.html — Biografia do protagonista monkey D. luffy com citações e marcações de texto.
 tripulacao.html — Apresentação dos membros do bando dos Chapéus de Palha.
 aliados.html — Lista de frotas, reinos e parceiros de batalha ao longo da jornada.
 inimigos.html — Detalhes sobre os principais antagonistas e facções oponentes.
 ilhas.html — Mapeamento das ilhas e territórios visitados com elemento de vídeo local.
 poderes.html — Explicação de akuma no mi, haki e medidores de evolução (<progress> e <meter>).
 sagas.html — Cronologia de arcos e sagas com lista expansível em <details>.
 curiosidades.html — Fatos marcantes e estatísticas sobre a obra e o autor.
 galeria.html — Exposição visual utilizando figuras com legendas (<figure> e <figcaption>).
 midia.html — Central de reprodução de áudios e vídeos locais do projeto.
 contato.html — Formulário de inscrição com seletores avançados e autocompletar.


-Recursos e Tags HTML Utilizados

-Tags Semânticas de Estrutura: <header>, <nav>, <main>, <section>, <article>, <aside>, <footer>.

-Multimídia Local:
  - <audio controls> para execução de efeitos sonoros.
  - <video controls> para reprodução de vídeos locais sem depender de plataformas externas.
  - <figure> e <figcaption> para agrupamento semântico de imagem e legenda.
-Formulário Avançado:
  - Campos do tipo date, file, color e range.
  - Validações nativas com required e dicas de preenchimento em placeholder.
  - Sugestões de preenchimento dinâmico com <datalist>.
-Elementos Interativos:
  - Bloco expansível nativo via <details> e <summary>.
-Marcação Avançada de Texto:
  - <abbr>, <mark>, <blockquote>, <cite>, <del>, <ins>, <progress> e <meter>.


-Como Executar o Projeto

1. Clone este repositório ou baixe os arquivos para o seu computador.
2. Acesse a pasta html/.
3. Abra qualquer um dos arquivos .html (por exemplo, biografia.html) diretamente em qualquer navegador web.
4. Utilize o menu de navegação localizado no topo para circular por todas as páginas do projeto.
